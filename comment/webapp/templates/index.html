How the scan works

01

Clean the text

The comment is lower-cased, expanded, corrected and lemmatised to strip noise before analysis.

02

Run the Bi-LSTM

A Bidirectional LSTM recurrent network reads the sequence in both directions for context.

03

Score each category

Seven independent scores are produced — toxic, severe toxic, obscene, threat, insult, hate, neutral.
